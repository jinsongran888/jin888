Windows 教程简述

  1. 下载 LetheLauncher-Distribution-7.zip —— 标着 Distribution 的 zip，不是 Source code
  2. 把「整个文件夹」解压到一个空目录（不是只拖 exe 出来）
  3. 运行里面的 LimbusCompany.exe（玫瑰图标）→ 自动更新并启动
  4. 出现问题：去 BepInEx/plugins/，把 Lethe.dll 换成 https://api.lethelc.site/Lethe.dll
  5. 重开游戏，进入服务器
  6. Linux / Wine 用户：启动项加 WINEDLLOVERRIDES="winhttp=n,b" %command%（有兼容问题切 Proton GE）
