插件整理（AI整理）

发表于2026-10-23|更新于2026-10-23|随笔
|浏览量:

DSH（DeepSeek Harness）这套东西好玩的地方在插件：界面、工具、提示词、挂件，全都能换。这里把我正在用的几个列一下，方便重装机器时照单捡回来。

刷视频和历史改写那两个按本人要求不列，剩下的都在。

一张表

插件 版本 干什么 仓库
dsh-550c-boot 0.4.0 启动片头 + 访问授权界面 yannicksong0106/dsh-550c-boot
dsh-ops 0.3.1 原生文件 / 命令工具（Win、Linux、Apple Silicon） T-Auto/dsh-ops
dsh-purge 1.1.72 破甲：按模型换提示词 YuJunZhiXue/dsh-purge
dsh-whale-widget 0.4.2 右下角余额小鲸鱼挂件 MeteorNOX/DeepSeek-Balance-Whale-Widget

dsh-550c-boot：开机先来一段 550C

启动时播一段 550C 片头，之后可以走一段可交互的访问授权界面，两套主题：UEG 联合政府 / 550C 控制终端。点击或 Enter 推进，Esc 直接跳过；通用设置里能关掉。

用途就一个：让每次开 DSH 都有点仪式感，而不是对着空白窗口发呆。

dsh-ops：把文件操作补齐

给 DSH 补原生文件工具和 PTC 工具，覆盖 Windows x64、Linux x64、macOS Apple Silicon；Windows 上还额外带 Bash 和 PowerShell 7 的可选载荷。

装它主要是为了让「读文件 / 写文件 / 跑命令」在三个平台上是同一套手感，不用来回切终端。

dsh-purge：提示词可换

破甲类插件，核心是按模型换不同提示词，默认那套面向国模「小码酱」。它把提示词层做成可替换的，模型换一个、提示词跟着换一套。

作者在 README 里写了署名要求，二开之前先看那一节。

dsh-whale-widget：右下角的小鲸鱼

DeepSeek 余额小鲸鱼挂件：常驻右下角，显示余额、今日已用、每轮消耗、峰谷定价。泡泡内容能完全自定义——点击序列、并列加权出泡、随机语句/随机图片、逐行样式与字体、悬浮快捷编辑、音效、吸附与翻转。

对我来说是最实用的一个：写东西时不看账单，月底就不会被账单看。

安装

都是标准 DSH bundle 插件，装法一致：

装完在 profile 的 bundles 里能看到对应条目，重启 DSH 生效。

一点经验

  • 插件冲突多半来自同一个位置被两个插件抢（比如右下角），先关一个再看
  • 界面类插件升级后记得硬刷新浏览器，不然看到的还是旧客户端
  • 本地的 link: 插件卸载前先备份，node_modules 清了就没了

清单会随装随更，下次重装照这张表捡。
